# 微信公众号知识库

## 触发条件
当用户发送微信公众号链接时，自动：
1. 识别链接格式
2. 爬取完整内容
3. 智能分析文章
4. 存档到知识库
5. 返回摘要给用户

## 工作流程

### 第一步: 链接识别
- 检测 `mp.weixin.qq.com` URL
- 提取文章 ID
- 验证链接有效性

### 第二步: 内容抓取
- 使用 web_fetch 获取正文（readability模式）
- 如失败，用 browser 工具模拟真实浏览器
- 添加请求延迟避免被封禁

### 第三步: 内容分析
- 提炼核心观点
- 识别关键数据
- 总结文章结构
- 生成洞察摘要
- 提取标签和分类

### 第四步: 知识库存储
- 按日期和主题分类
- 添加索引
- 生成元数据(标题/作者/时间/标签)
- 保存为 Markdown 格式

### 第五步: 用户反馈
- 返回分析摘要
- 显示存档路径
- 提供后续检索建议

## 技术实现

### 链接识别
- 使用正则表达式匹配 `mp.weixin.qq.com`
- 提取文章 ID 和标题

### 内容抓取
- 优先使用 web_fetch 的 readability 模式
- 失败时使用 browser 工具
- 实现请求延迟和重试机制

### 内容分析
- 提取标题、作者、发布时间
- 分析文章结构和要点
- 生成摘要和关键词
- 自动分类和标签

### 知识库管理
- 按日期组织文件
- 生成 JSON 索引
- 支持快速检索
